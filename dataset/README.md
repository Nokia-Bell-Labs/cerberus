### Multi-Modal PII Datasets
- [Generate notebook](Generate.ipynb) showcases how to generate multimodal PII datasets. Different sections are separated in the notebook for different datasets.
- [Scanify](Scanify.ipynb) demonstrates how to generate scanned document effect on existing multimodal(image) datasets. 
- [Evaluate notebook](Evaluate.ipynb) showcases how results from LLM responses are examined to see whether PII is controlled in new generation.
- Generated data will be stored in [data directory]('./data/')
